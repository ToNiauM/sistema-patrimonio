# Mapa manual → procedimentos

Este mapa relaciona os principais trechos do Manual de Gestão Patrimonial do
CFC às sete áreas operacionais do portal. Ele serve como ponto de partida para
a redação dos procedimentos que serão publicados nas próximas fases.

Para ler o contexto normativo antes de usar a tabela, consulte a página
[Manual do CFC](manual-cfc.md).

## Como usar o mapa

O link da coluna **Área** abre uma seção que já existe no portal. O nome da
coluna **Procedimento-alvo** ainda é apenas texto quando o procedimento não foi
publicado; ele será transformado em link nas Fases 4 e 5.
