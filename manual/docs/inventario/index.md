# Inventário

Esta área reúne os procedimentos operacionais de Inventário patrimonial do CFC — o levantamento periódico dos bens móveis para conferência física do acervo, identificação de divergências e atualização dos registros no SBP.

Os procedimentos em preparação cobrirão o planejamento, a execução da contagem e o tratamento das divergências apuradas no inventário.
