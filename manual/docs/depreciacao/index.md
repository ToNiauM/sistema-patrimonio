# Depreciação

Esta área reúne os procedimentos operacionais de Depreciação patrimonial do CFC — a depreciação é realizada automaticamente pelo SBP. O patrimônio exporta os lançamentos para contabilidade, que por sua vez realiza os registros sintéticos.

Os procedimentos em preparação cobrirão o cálculo, o lançamento e a conferência da depreciação dos bens sujeitos a esse controle.

## Procedimentos da área

- **[Depreciação e exportação para contabilidade](depreciacao-exportacao/index.md)**
  Executar o fechamento do mês no SBP, processar a depreciação dos bens patrimoniais e exportar os lançamentos contábeis para importação pelo departamento contábil.
