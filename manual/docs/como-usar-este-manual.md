# Como usar este manual

Este manual foi criado para que qualquer colaborador, mesmo sem experiência anterior em patrimônio ou nos sistemas utilizados, consiga realizar as rotinas patrimoniais com segurança e autonomia.

## Navegação pelo menu lateral

O menu à esquerda organiza os procedimentos por **área operacional**:

- **Entrada de Bens** — incorporação de novos bens ao patrimônio.
- **Movimentação e Transferência** — mudança de local ou responsável.
- **Termos e Relatórios** — geração de documentos patrimoniais.
- **Processos no SEI** — abertura de processos relacionados às rotinas.
- **Depreciação** — ajuste do valor patrimonial ao longo do tempo.
- **Inventário** — levantamento periódico dos bens.
- **Desfazimento e Baixa** — retirada de bens do patrimônio.
- **Sistema de Patrimônio e Inventário** — o manual do sistema web da Geserv, tela a tela: entrar, pesquisar,
  emitir termos, manter cadastros, atualizar a base e conduzir o inventário. Comece pela
  [visão geral](sistema/index.md), que mostra o que cada função de usuário pode fazer.

Clique em uma área para expandir as páginas disponíveis. O item atual aparece em destaque no menu.

## Pesquisar procedimento, sistema ou palavra-chave

Use o campo de busca no topo da página para localizar qualquer procedimento pelo nome, pelo sistema (SEI, SBP, SGA) ou por palavras do conteúdo.

Os resultados de busca abrem diretamente na seção correspondente do procedimento, quando a âncora de título estiver disponível. Quando não houver âncora, o resultado abre no topo da página e você pode navegar pelo índice lateral para localizar o trecho desejado.

!!! tip "Dica"

    Para localizar o procedimento modelo de referência, pesquise `procedimento modelo patrimonial`.

## Índice interno de cada página

Páginas de procedimento apresentam um índice à direita com os títulos das seções. Clique em um título para ir diretamente àquela parte da página — útil para retomar uma etapa específica durante a execução.

## Avisos e alertas

Os procedimentos usam quatro tipos de destaque:

- **Nota** — informação complementar útil.
- **Dica** — sugestão para facilitar a execução.
- **Cuidado** — ação que requer atenção para evitar erros.
- **Perigo** — ação que pode causar consequências difíceis de reverter.

Leia os avisos antes de executar o passo correspondente.

## Sistemas envolvidos

Os procedimentos deste manual utilizam estes sistemas:

| Sistema | Finalidade |
|---------|------------|
| **SEI** | Sistema Eletrônico de Informações — abertura e tramitação de processos |
| **SBP** | Sistema de Bens Patrimoniais — registro e controle do patrimônio |
| **SGA** | Sistema de Gestão de Ativos — gestão e movimentação de bens |
| **Sistema de Patrimônio** | Sistema web da Geserv — termos de responsabilidade e de devolução, cadastros de responsáveis, atualização da base a partir do SPW e inventário (veja a parte [Sistema de Patrimônio e Inventário](sistema/index.md)) |

O SGA foi desenvolvido pelo empregado Antônio Rodrigues de Sousa Júnior, então supervisor do extinto Setor de Patrimônio, com o intuito de otimizar a realização de inventários patrimoniais. Não é um sistema de propriedade do CFC.

Caso você não tenha acesso a algum desses sistemas, entre em contato com o setor responsável antes de iniciar o procedimento.

## Conteúdo em preparação

Algumas áreas ainda estão sendo documentadas. Páginas marcadas como **Conteúdo operacional em preparação** serão preenchidas nas próximas fases. Consulte o [procedimento modelo](procedimento-modelo/index.md) para conhecer a estrutura que cada página seguirá.

## Sobre os checklists

Futuras versões deste manual incluirão checklists que permitem marcar o progresso durante a execução de um procedimento. O estado ficará salvo no seu navegador e não será enviado a nenhum sistema.

!!! warning "Cuidado"

    Os checklists são auxiliares de execução local. Eles **não** geram registro oficial, **não** substituem a abertura de processo no SEI e **não** ficam visíveis para outras pessoas.

## Dúvidas e atualizações

Este manual é mantido pelo Setor de Patrimônio e atualizado conforme os procedimentos evoluem. Se encontrar uma instrução desatualizada ou incompleta, comunique ao responsável pelo setor.
